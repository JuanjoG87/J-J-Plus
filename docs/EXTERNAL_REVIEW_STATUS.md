# External Review Status

**Public Review 0.1 is an invitation to review. It is not a claim of independent peer review.**

As of this document's publication:

- the repository contains internally gated and reproducibly checked artifacts;
- no independent external reviewer is claimed as having validated the full compiler or authority model;
- no academic peer-review claim is made;
- no formal-verification claim is made.

Terminology used by this repository:

- **gated / validated** — passed the project's documented automated or reproducibility checks;
- **internally audited** — inspected within the project using its own creator/rival process;
- **externally reproduced** — reserved for results independently reproduced by a third party;
- **externally reviewed** — reserved for review attributable to an identifiable independent reviewer;
- **Public Review** — the name of the publication phase and an invitation for outside scrutiny.

If you independently reproduce or falsify a result, opening an issue with the exact environment, command, input, and observed output is more useful than a general endorsement.
