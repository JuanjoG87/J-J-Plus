# Estado de revisión externa

**Public Review 0.1 es una invitación a revisar. No es una afirmación de peer review independiente.**

Actualmente:

- el repositorio contiene artefactos con gates internos y comprobaciones reproducibles;
- no se afirma que un revisor externo independiente haya validado el compilador completo o el modelo de autoridad;
- no se afirma revisión académica;
- no se afirma verificación formal.

Terminología:

- **gated / validated**: pasó checks documentados del proyecto;
- **internally audited**: inspeccionado mediante el proceso interno creador/rival;
- **externally reproduced**: reservado para un tercero que reproduzca un resultado;
- **externally reviewed**: reservado para una revisión atribuible a una persona independiente identificable;
- **Public Review**: nombre de la fase de publicación e invitación al escrutinio externo.

Una reproducción o falsificación independiente con entorno, comando, input y output exactos vale más que un respaldo general.
