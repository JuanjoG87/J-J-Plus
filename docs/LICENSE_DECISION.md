# License Decision Before Open-Source Release

The current package preserves the existing OMEGA Research Source Notice. It is source-visible but not an OSI-style open-source license.

This is deliberate: changing to MIT, Apache-2.0, MPL-2.0, GPL-family terms or another license grants legal permissions and should be a conscious project decision, not an automated packaging change.

A GitHub repository can be made public with the current notice for review, but it should be described as **source-visible public review**, not open source.

## Preview.14 publication boundary

Once the clean-extraction release gate in `docs/GITHUB_PUBLICATION_CHECKLIST.md` passes, Preview.14 is technically suitable to publish in a public GitHub repository **for source-visible review under the current notice**. That readiness does not alter the license, freeze the ABI, or imply production maturity.
